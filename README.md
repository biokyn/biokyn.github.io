# BioKyn website

Source for [biokyn.js.org](https://biokyn.js.org), the BioKyn project site. A single static `index.html`, with no build step.

## Develop
Open `index.html` in a browser, or serve the folder: `npx serve .`

## Deploy
GitHub Pages serves the `main` branch root. `CNAME` maps the custom domain (registered via [js.org](https://js.org)).
