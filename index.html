Architectural Blueprint

The Three Layers That Make BioKyn Unfakeable

Bots can generate smooth lines or random noise, but they cannot simulate biological muscle physics on genuine consumer silicon.

01

Involuntary Neuromuscular DSP

Humans cannot move a pointer or touch a screen in mathematically perfect lines. Muscle motor units fire in involuntary, microscopic 8 Hz to 12 Hz tremors. BioKyn extracts this tremor ratio via a client-side Web Worker running Welch Power Spectral Density.

• Minimum Jerk Derivation
• Nyquist-Clamped FFT Analysis
• Dynamic 100 Hz Interpolator
02

Silent Hardware Enclave Anchor

Headless bot farms run on virtualized AWS or DigitalOcean servers. BioKyn queries the user's native hardware security chip (Apple Secure Enclave, Android StrongBox, Windows TPM) via a silent WebAuthn assertion without popping up any permission dialogs.

• Silent WebAuthn Level 3
• Non-Exportable CryptoKey Fallback
• Anti-CDP Automation Detection
03

Zero-Knowledge Blind Tokens

The server never receives raw mouse coordinates, touch pressure, or hardware identifiers. The client blinds the attestation point using RFC 9497 VOPRF over ristretto255-SHA512. The server signs a blind Privacy Pass token without learning who the user is.

• RFC 9578 Privacy Pass Tokens
• In-Memory Replay Nullifier Cache
• Constant-Time Scalar Multiplication

Developer Integration

Drop-In Replacement for Any CAPTCHA

Two lines of code. Zero third-party SaaS dependencies.

client-and-server-demo.ts
npm install @biokyn/core 
// 1. CLIENT INTEGRATION (Frontend)
import { BioKynClient } from '@biokyn/client';

// Initialize invisible background listener
const biokyn = BioKynClient.init({
  issuanceEndpoint: '/api/biokyn/issue'
});

// Passively generate token on user form submit (<150ms)
form.addEventListener('submit', async (e) => {
  e.preventDefault();
  const token = await biokyn.getToken(); // Zero puzzles shown
  
  await fetch('/api/login', {
    headers: { 'X-BioKyn-Token': token }
  });
});

// ----------------------------------------------------
// 2. SERVER INTEGRATION (Express / Next.js)
import { BioKynServer, biokynMiddleware } from '@biokyn/server';

const server = new BioKynServer({ serverPrivateKey: process.env.BIOKYN_SECRET });

// Protect sensitive routes with zero-knowledge verification
app.post('/api/login', biokynMiddleware(server), (req, res) => {
  res.json({ success: true, message: "Living human verified deterministically!" });
});
